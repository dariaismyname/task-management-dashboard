# Task Management Dashboard

A small task management dashboard built with **React 18, Redux, Redux-Saga, Reselect, and Chakra UI** as a technical test project.  
It demonstrates Redux store setup, saga handling with retries and optimistic updates, and UI components with Chakra.

---

## ▶️ Getting Started

Clone the repo and install dependencies:

```bash
git clone <repo-url>
cd task-management-dashboard
npm install
```
Build for production:
```bash
git clone <repo-url>
cd task-management-dashboard
npm run build
```
